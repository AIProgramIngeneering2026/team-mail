# ADR-0003. В первой версии нет аутентификации клиентов

Дата: 2026-11-14. Статус: принято.

## Контекст и ограничения
Реальных персональных данных нет.

## Решение
Аутентификации нет. Идентификатор Job это случайный UUID, который нельзя
угадать. Несуществующий id и «чужой» id дают одинаковый ответ 404 not_found,
чтобы не раскрывать, существует ли задание.

## Альтернативы
- API-ключ на клиента с привязкой Job к ключу: безопаснее, но избыточно для одного клиента.
- OAuth: сильно избыточно.

## Цена решения
Любой, кто знает id, видит статус Job. Лимитов по клиентам нет.

## Условия пересмотра
Появление второго клиента или реальных персональных данных.
