# team-mail
# Сервис уведомлений

## Проблема
Небольшим сервисам нужно отправлять напоминания и оповещения, но каждый раз
писать отправку, повторы при сбоях и учёт статусов заново долго и ненадёжно.

## Для кого
- Разработчики небольших приложений (запись, напоминания, оповещения)
- Администраторы, которым нужно знать, дошло ли сообщение

## Что входит в систему
- Приём запроса на отправку сообщения по API
- Доставка через email и Telegram
- Повторные попытки при сбое канала
- Учёт статусов и отмена

## Что точно не входит
- Интерфейс
- Рассылки на тысячи адресов
- Реальные персональные данные и платежи
