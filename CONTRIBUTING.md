# Правила работы

## Ветки
feature/, fix/, docs/.

## Коммиты
Одна мысль на коммит, сообщение по-русски в повелительном наклонении,
например «Добавить проверку адреса».

## Review
В review должны быть
замечания по сути. 

## Definition of Done
Задача готова, когда:
- изменение влито через PR в main;
- пройден review;
- критерии приёмки из docs/requirements.md выполнены;
- есть автотест на новое поведение (для кода);
- README или документация обновлены;
- issue закрыта со ссылкой на PR.
